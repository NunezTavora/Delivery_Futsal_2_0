DELIVERY FUTSAL 2.0 · TEMPORADA 2026/27

CONTENIDO
- index.html: aplicación web.
- manifest.webmanifest + sw.js: instalación y caché PWA.
- icon-192.png / icon-512.png: iconos de la app.

PUBLICAR EN GITHUB PAGES
1. Descomprime el paquete.
2. En el repositorio de GitHub Pages de Delivery Futsal, sustituye el index.html anterior por este index.html y añade manifest.webmanifest, sw.js, icon-192.png e icon-512.png en la misma carpeta raíz.
3. Haz commit/push y espera a que GitHub Pages publique los cambios.
4. Abre la web en Chrome Android y usa el menú ⋮ > Instalar aplicación / Añadir a pantalla de inicio.

DATOS
Esta primera versión guarda resultados, plantilla y estadísticas en el almacenamiento local del navegador. La aplicación conserva la clave de resultados anterior deliveryFutsal2627 para mantener los marcadores de este dispositivo. Para compartir y editar los mismos datos entre todos los móviles se necesita conectar una base de datos online y configurar permisos de administrador.
